# Effects & component sources + inspection tools

Licence rule of thumb:
- **MIT/Apache** = copy in, keep the notice.
- **MIT + Commons Clause** = use inside our product, never resell or redistribute the components.
- **Inspiration galleries** = learn the technique, rebuild it (see `reverse-engineer-ui`).

## Component / effect libraries
| Resource | What it is | Use when | Licence / cost | Verdict |
|---|---|---|---|---|
| **Canvas UI**, canvasui.dev ([repo](https://github.com/DavidHDev/canvas-ui), ~5k★, active Oct 2026) | 35 "HTML-in-canvas" GPU effects (Liquid, Glass, Shatter, Particle Reveal, VHS, Ripple, Magnify…) in WebGL/WebGPU. React/Solid/Preact/Vue/Svelte/vanilla. Installed via shadcn registry (`npx shadcn@latest add @canvas-ui/<name>-react`), so code is copied into the repo | A hero or one showcase moment needs a GPU effect over real HTML | Free. **MIT + Commons Clause** (no reselling/redistributing the components) | **WEAK → KEEP for showpieces.** Live HTML-on-canvas needs an *experimental Chrome flag*; other browsers fall back to plain HTML. Never put core UI behind it. Check reduced-motion and GPU cost (frontend-performance) |
| **React Bits**, reactbits.dev ([repo](https://github.com/DavidHDev/react-bits), ~49k★) | Same author. Large set of animated React text/background/component effects | Text effects and animated backgrounds for marketing pages | Free. MIT + Commons Clause | **KEEP (with taste filter).** HN regulars call much of this genre "visual noise" ([HN](https://news.ycombinator.com/item?id=40456311)). Use one, not five |
| **Magic UI**, magicui.design ([repo](https://github.com/magicuidesign/magicui), ~23k★) | shadcn-style animated components (border beam, marquee, number ticker…) | A Tailwind + shadcn stack wants polished micro-effects | **MIT**, free | **KEEP.** Same "noise" caveat. Inspect for `transition: all` / layout animation before adopting |
| **Fancy Components**, fancycomponents.dev ([repo](https://github.com/danielpetho/fancy), ~3k★) | Eye-catching open-source text/interaction components (linked from floguo's hub) | Playful text/typography motion | **MIT**, free | **KEEP** (last push Mar 2026, so check it still builds) |
| **shadcn/ui** + registries, ui.shadcn.com (~126k★) | Accessible primitives, plus the registry mechanism most libs above install through | Base primitives. Also the install path for Canvas UI/Magic UI | **MIT**, free | **KEEP**, the default substrate |
| **21st.dev** ([repo](https://github.com/serafimcloud/21st)) | Community marketplace of shadcn/Tailwind components | Breadth search for a pattern | Per-component licences vary. Repo last pushed May 2025 | **WEAK.** Quality and licence vary per item, so verify each |
| **Awwwards Elements**, e.g. [Canvas grid, Fiddle.Digital](https://www.awwwards.com/inspiration/canvas-grid-fiddle-digital-design-agency) | Curated clips of award-site effects. "Canvas grid" is tagged canvas/WebGL/grid/interaction, desktop + mobile, with no code | Finding a *direction* for an effect, then reverse-engineering the live site | Free to browse. Effects are the agencies' work (rebuild, never copy) | **WEAK as a source, KEEP as inspiration.** The page itself has no implementation detail (preview didn't load for us). HN has a long-running view that award sites favour spectacle over usability ([2013](https://news.ycombinator.com/item?id=5582842)), so pair it with frontend-performance |
| **Codrops**, tympanus.net/codrops | Tutorials + demos of WebGL/CSS effects (e.g. "Recreate Stripe's lava-lamp gradient with Three.js", 2022) | Learning *how* a famous effect is built, step by step | Free. Demo licences vary per repo | **KEEP for learning** (blocks bots, so read it in a browser) |

## Inspection / extraction tools (feed `reverse-engineer-ui`)
| Tool | What it is | Use when | Licence / cost | Verdict |
|---|---|---|---|---|
| **Chrome DevTools MCP** ([repo](https://github.com/ChromeDevTools/chrome-devtools-mcp), ~54k★, Google, pushed Oct 2026) | MCP server: `evaluate_script`, `get_css_styles`, `take_screenshot`, `resize_page`, `hover`, `list_network_requests`, `performance_start_trace`/`analyze_insight`, `lighthouse_audit`, `screencast_start` | Default for reading computed styles, animations, assets and perf on a live page | Apache-2.0, free | **KEEP**, primary |
| **Playwright** | Browser automation. `page.evaluate`, `emulateMedia({reducedMotion})`, screenshots | Repo already uses it, or for scripted multi-state captures | Apache-2.0 | **KEEP** |
| **REA**, [morluto/rea](https://github.com/morluto/rea) (`rea-agents` on npm) | Real, MIT, very active (v6.5.0, commits daily). MCP + CLI that **bundles** RE engines (Ghidra/IDA/Hopper/Frida/JADX) for binaries, Electron, .NET, APKs, and **websites over CDP** (`inspect_web_page`, `analyze_web_bundle`, `inspect_web_event_listeners`, `observe_web_session`, screenshots) | JS-heavy behaviour: which handler fires, which bundle chunk, source maps, network flow | MIT, free. Node 22.19+/24.11+/26+. Commercial engines licensed separately | **WEAK for UI work.** No computed-style or animation-timing reader, and independent tests found incomplete UI/window coverage ([DEV/AgentConn](https://dev.to/max_quimby/rea-hit-248k-stars-the-real-story-is-scarier-2m12)). ~288k★ in 6 months: growth questioned but not proven fake ([zephel01](https://note.com/zephel01/n/n9d2ed82dcd4d?hl=en)). **Impostor repos exist**, so install only `rea-agents`. HN (807 pts) is split: "why not just give the agent Ghidra/radare2?" |
| **Agentation**, agentation.dev | In-page toolbar. Click elements → markdown with CSS selectors, source paths, React tree and **computed styles** for the agent. Can pause animations | Annotating *our own* app for an agent, and freezing an animation frame | Free for individuals and internal company use | **KEEP** (for our own UI only) |
| **DevTools Animations panel** | Built into Chrome: scrub, slow-mo, inspect keyframes/easing | Manual timing reads. Validating our rebuild | Free | **KEEP** |
| **`document.getAnimations()`** | Returns CSS animations, CSS transitions and WAAPI in one array ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/Document/getAnimations)) | The fastest timing read in any of the browsers above | Web standard | **KEEP** |
